# Anime Center

O projeto Anime Center exibe em um card animes aleatórios, foi uma entrega da primeira sprint do meu curso no SENAI, para o professor Atila









## Autores

- [@DevCaiobo](https://github.com/DevCaioBO/sprintfrontatila)


## 🚀 Sobre mim
Eu sou um desenvolvedor jovem iniciante que desenvolveu o projeto Anime Center para contribuir no meu conhecimento sobre componentes React





## Funcionalidades

- Expôr animes aleatórios
- Botão que chama um novo anime
- Com um F5 gera um novo anime
- Filtra, evitando conteúdos sem necessidade


## Roadmap

- Construir um componente card para expôr um anime aleatório

- Construir o botão que dispara a função de chamar animes aleatórios
